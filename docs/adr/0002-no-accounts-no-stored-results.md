# No accounts and no stored results

The 2019 version had login, roles, an admin area, e-mailed results and progress charts. The rebuild drops all of them. A Player only types a name to be greeted, and nothing about Rounds is kept after the Round summary closes. The goal is teaching the clock, not tracking children. Without a backend or personal data, the game can be a static offline PWA with no privacy obligations. Adding persistence later means new storage and new privacy work. Don't reintroduce it casually.
